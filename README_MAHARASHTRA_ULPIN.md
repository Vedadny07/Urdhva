# Maharashtra ULPIN integration

URDHVA keeps official ULPIN as a **parcel-level identifier**. Floor and unit identifiers generated by URDHVA are separate vertical identifiers and are never presented as official ULPINs.

## Current integration

The unified top search bar recognizes an exact 14-digit numeric ULPIN as a Maharashtra ULPIN query and calls:

`GET /api/maharashtra/ulpin?ulpin=<14-digit-ulpin>`

The backend is a configurable **Mahabhumi API adapter**. It deliberately does not invent or assume a private government API endpoint. Configure these environment variables only when you have an authorized machine-to-machine endpoint:

- `MAHABHUMI_ULPIN_API_URL`
- `MAHABHUMI_ULPIN_API_METHOD` (`GET` or `POST`)
- `MAHABHUMI_ULPIN_QUERY_PARAM` (default `ulpin`)
- `MAHABHUMI_API_KEY` (optional)

When the adapter resolves a parcel, URDHVA can display jurisdiction fields, parcel dimensions, coordinates and parcel geometry and highlight the official parcel in the geographic map.

When the adapter is not configured, URDHVA returns a clear provider status plus links to the official Maharashtra services instead of guessing a parcel location.

Official services:

- MAH LGD ULPIN jurisdiction lookup: https://mahavillages.mahabhumi.gov.in/newjurisdiction.php
- Bhu-Naksha: https://mahabhunakasha.mahabhumi.gov.in/mobile/www/index.html
- Mahabhumi API portal: https://api.mahabhumi.gov.in

## Parcel -> Building -> Floor -> Unit

The intended data relationship is:

Official parcel geometry + ULPIN
→ real building footprint (Overture/OSM)
→ source height/floors where available
→ URDHVA survey data (LiDAR/drone/GNSS) for measured height/floor segmentation
→ URDHVA floor/unit identifiers

No ownership, flat, floor, height, parcel or coordinate value is fabricated.
